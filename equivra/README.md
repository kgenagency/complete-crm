# COMPLETE CRM · EQUIVRA

CRM za EQUIVRA DOO DOLOVO (aukcijska kuća konja). Isti Supabase projekat kao ostali moduli, tabele `e_*`.

Live: https://kgenagency.github.io/complete-crm/equivra/

- Prijava: korisničko ime + lozinka (nalog `ime@complete-crm.local` u Supabase Auth). Sesija se pamti u pregledaču.
- Šema: `schema.sql` (pokreće se jednom u SQL editoru, bezbedno za ponavljanje).
- Veza sa sajtom (equivra-aukcije.lovable.app): Podešavanja → Veza sa sajtom, prijava admin nalogom sajta, zatim „Sinhronizuj sa sajtom".
- Ekrani: Danas, Kontakti, Pipeline (prodavci, kupci, naplata 5% + 5%), Konji (Pronađi kupce), Marketing (segmenti, šabloni, kampanje za e-mail, Viber, WhatsApp uz saglasnost), Kalendar, Istorija, Podešavanja.
